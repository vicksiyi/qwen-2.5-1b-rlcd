# Snake 策略优化评估

日期：2026-09-19。Apple M4，项目固定版本 Qwen2.5-1.5B-Instruct-4bit，temperature=1。

每局 16×16 棋盘，初始蛇为 (8,8)、(7,8)、(6,8)，朝右；第一颗食物在 (11,8)。种子 0 和 1，最多 80 步。每种策略独立重置同一随机种子，在吃到食物后从当时的空格中随机选新食物；由于蛇身不同，后续食物位置可能不同，并非完全相同的状态序列。所有策略开启一步防撞。

| 种子 | 策略 | 吃到食物 | 最近 24 步内重访次数 | 防撞调整 | 规划调整 | 结束原因 |
|---|---|---:|---:|---:|---:|---|
| 0 | classic | 2 | 1 | 3 | 0 | step_limit |
| 0 | enhanced | 0 | 77 | 0 | 0 | step_limit |
| 0 | hybrid | 9 | 0 | 0 | 65 | step_limit |
| 1 | classic | 6 | 0 | 0 | 0 | step_limit |
| 1 | enhanced | 0 | 77 | 0 | 0 | step_limit |
| 1 | hybrid | 8 | 0 | 0 | 67 | step_limit |

## 结论

本次小样本中：原版平均 4 个食物，规划辅助平均 8.5 个。规划辅助在 160 步中进行了 132 次规划调整，提升主要来自算法筛选，不能解释为语言模型推理能力提升。丰富状态实验版两局均为 0 个，且频繁循环；信息变多不一定提高小模型决策质量，因此保留为实验对照，不作为默认玩法。

这是短局功能评估，不是通关率或普遍性能结论；各局均运行到步数上限。尚未评估长蛇、接近满盘等长局分布。原始 JSON 中耗时受到并行测试与本机负载影响，不用于速度对比。

## 实现要点

- 保存最近 24 个蛇头位置和未进食步数，吃到食物/重开后清空。
- 路线逐步模拟蛇身移动和增长，检查 6 步内的生存可能与进食后的尾巴连通性。
- 路径搜索有明确上限，未找到路线不会被当作确定死亡。
- 规划辅助优先选预测可逃离的短路线；无可行食物路线时，优先生存与减少重复。
- 始终显示原始模型概率、模型首选和执行动作，分别统计防撞与规划调整。
